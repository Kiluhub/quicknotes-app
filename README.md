# QuickNotes

QuickNotes is a simple note-taking web app built with HTML, CSS and JavaScript. You can add notes, give each one a category, search them, and delete them. Notes are saved in your browser, so they are still there after a refresh.

## Features

- Add notes with a category (Personal, Work or Study)
- Each note shows its text, category, date and time, and a Delete button
- Validation: empty notes and notes over 200 characters are rejected with a message
- Live note count ("You have 3 notes.")
- Search notes as you type (not case-sensitive)
- Notes are saved with localStorage
- Responsive layout that works on phones
- Bonus: "Clear all" button with a confirmation prompt

## How to run

1. Download or clone this repository.
2. Open `index.html` in any modern browser.

No installation or build step is needed.

## Files

- `index.html` - page structure
- `style.css` - layout, colours and responsive styles
- `script.js` - adding, deleting, validating, saving and searching notes
- `README.md` - project documentation

## Technologies

HTML5, CSS3 (Flexbox, media queries), JavaScript (DOM, events, localStorage)
